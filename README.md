# Discord Rich Presence

A customizable Discord Rich Presence application written in Python.

## Features

- Change activity details and state.
- Change large and small images.
- Customize activity buttons.
- View current settings.
- Reset settings to default values.
- Activity timer.

## Requirements

- Python 3.10+
- Discord Desktop
- pypresence

## Installation

1. Clone the repository:

   git clone https://github.com/witchblxvdes/custom_ds_rpce.git

2. Navigate to the project directory:

   cd custom_ds_rpc

3. Create a virtual environment:

   python -m venv venv

4. Activate the environment:

   .\venv\Scripts\activate

5. Install dependencies:

   pip install -r requirements.txt

## Usage

Run the application:

python main.py

Make sure Discord Desktop is running.
